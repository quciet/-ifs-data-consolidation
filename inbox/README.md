# New IFs data requests

Put downloads here, optionally in a folder per source/request. Include a source URL,
release/version and a short note describing which IFs indicators to update. Source
documentation and codebooks are useful for unfamiliar datasets.

Ask Codex in this project to process the new files. `ingest` creates a timestamped
request folder and archives the input plus recipe and country mapping. Files added
here do not trigger processing automatically. Downloads and request folders are
excluded from Git; back them up separately.
